A guide to the original SVG controls

Follow the threads.

Start with a built-in pattern, then explore its colors and structure. The editor uses three strip directions and three hex weave layers.

Open MadWeaver →

Your first pattern

  1. Choose one of the five pattern previews near the upper left.
  2. Choose a pattern color count from 1–6 in the far-left column.
  3. Select one of the eight color swatches along the top.
  4. Move over the weave until a black outline identifies a strip, then click to recolor it.
  5. Adjust the selected palette color using the four sliders near the upper right.

Changing a palette color updates every strip using that swatch. Palette size (eight swatches) and pattern color count (one to six) are separate controls.

Control reference

Location / labelWhat it does
Left / five previewsApply a built-in color pattern. Resets manual strip colors and individual visibility.
Far left / 1–6Set the built-in pattern's color count. Also resets manual strip edits.
Lower left / 1–8Set 3, 6, 9, 12, 15, 18, 21, or 24 strips per direction. Changing the strip count resets manual strip edits.
Top / eight swatchesSelect the color to paint with or edit.
Upper right / four slidersAdjust opacity, hue, saturation, and value, in that order from top to bottom.
Top right / four recent colorsReplace the selected swatch with a recent color. This is color history, not a full undo history.
Top left / I and VI makes a clicked strip invisible; V makes it visible without recoloring it. Selecting a palette swatch returns to painting.
Right / −, X, CChange handedness, flip top and bottom, or shift the pattern's center.
Right / a, b, cShow or hide the three hex weave layers.
Right / H, R, LShow or hide the horizontal, upward-right, and upward-left strip directions.
Right / L below direction controlsToggle strip outlines. This L is separate from the direction L above it.
Lower right / N, M, W, ENarrow, medium, wide, and extra-wide strip spacing.
Bottom / HBHide the controls. Click the same location to show them again.

Export your artwork

On the editor page, choose Export artwork as SVG. The download preserves the current colors, visibility, spacing, and interlacing, and removes controls and scripts. It is a static vector image, suitable for viewing or conversion in a vector editor.

Export does not save an editable project. Keep the editor tab open to continue working. There is no autosave, project import, or full undo. Reloading or leaving the page loses changes in that tab.

The original engine can restore its state from a serialized SVG DOM containing the controls, custom attributes, and script reference. Browser “Save As” behavior varies, and downloading the source SVG may only save the original design. Editable file saving is a future improvement, not a guaranteed browser workflow.

Browser and device notes

The current editor is tested in desktop Chromium. It uses native SVG and JavaScript; no Adobe plug-in, Java, or Batik installation is needed for the web editor. Firefox, Safari, and physical touch devices have not been verified in this update.

The original controls rely on mouse hover and mouse-down events. Use a mouse or trackpad. The embedded editor keeps a minimum width for legible controls; scroll horizontally on narrow screens. The surrounding website supports keyboard navigation, but the SVG editor does not provide complete keyboard operation.

History and further reading

Richard Harris's original program and examples are preserved in this repository. The 2012 project notes include historical browser and conversion instructions. Read them as an archive; references to browser plug-ins and old download links are not current setup instructions.

Original handbook notes describe Handbook of Triaxial Weaves: A Guide to HexWeave and MadWeave, by Elizabeth Harris and Charlene St. John. The historical page's publication statement has not been independently updated.
