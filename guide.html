Planar and corner editing

User guide

The planar editor uses three strip directions and three hexweave classes. This guide describes its controls, the supported corner mode, and project saving and SVG export.

Open editor

Planar mode

  1. Choose one of the five pattern previews near the upper left.
  2. Choose a pattern color count from 1–6 in the far-left column.
  3. Select one of the eight color swatches along the top.
  4. Move over the weave until a black outline identifies a strip, then click to recolor it.
  5. Adjust the selected palette color using the four sliders near the upper right.

Changing a palette color updates every strip using that swatch. Palette size (eight swatches) and pattern color count (one to six) are separate controls.

After I or V, the first palette-swatch click returns to painting with the previous swatch still selected. Click the desired swatch again to select it.

Corner mode

Choose Corner in the editor's Design mode control. This opens a supported construction; it does not convert arbitrary planar edits. Both modes keep their unsaved colors and selections while this tab stays open. Save Project stores only the active design, so save each design separately before closing the tab.

Choose the hole/weave phase, reference angle and circular crop together, then choose Apply together. The current catalogue contains 84 certified constructions, with angles from 60° to 720°. This is a finite prototype catalogue, not the eventual allowed-angle list. Monochrome madweave retains the general 60° baseline. Invalid geometry and unsupported combinations are reported without replacing the drawing. A construction change replaces custom colors and selection as disclosed in the proposal.

Use the same eight palette swatches, recent colors and opacity/hue/saturation/value sliders. Click material to paint its entire joined strip, including hidden material and seam partners. The five pattern previews use the existing three-label formulas; 1 chooses monochrome and 3 chooses a formula. Formula changes replace manual colors. Counts 2/4/5/6 and independent size, spacing, C/hand/X, direction filters and I/V material hiding are unavailable in corner mode. The a/b/c buttons stage the corresponding certified hexweave phase.

Seam color changes are allowed and show a vivid pink warning marker. Hover over the marker or focus it for details. Colors are retained, but color continuity is not Validated. Equal RGBA colors in different palette slots are equivalent; changing an aliased color can expose a warning. Transparency remains available. Transparent material is still present in the model.

Open Strip and seam inspection to inspect complete joined strips, select hidden positions, or cycle the positions at a crossing. The palette buttons work with Enter/Space; sliders also accept left/right arrows. Use Paint selected strip for keyboard painting. Both distinct positions at a self-crossing remain inspectable. The outline button draws material edges; dashed hidden pieces are a separate inspection option.

The shared Open action accepts existing planar projects and Stage 3A/3B corner files. Saved files reopen with editing, both modes, resaving and SVG export offline. Only active applied settings are saved. Corner SVG is diagram artwork; choose explicitly whether to include inspection and warning markers. Warning counts remain in its caption and metadata. Physical constructibility is unverified. No fabrication templates or physical-validation claims are provided.

Save and reopen an editable project

  1. Choose Save Project on the editor page.
  2. Your browser downloads madweave-project.html. This single file includes your design, the editor, and its pattern images.
  3. Open the downloaded HTML file in a browser to continue editing, even offline. You can also choose Open Project on the website and select the file.
  4. After further edits, choose Save Project again. This downloads an updated copy; it does not overwrite the earlier file automatically.

Rename files to distinguish designs and versions. Browsers may append a number when a filename already exists. A saved project preserves strip colors and visibility, all palette colors and opacity, recent colors, size, pattern settings, spacing, orientation, visible layers and directions, the current paint/hide/show mode, and hidden controls.

Open Project also accepts original editable MadWeave SVG files saved with the old program. It reads their design state and rebuilds the editor. Static SVG artwork exports have no editor controls and cannot be reopened as editable projects.

There is no autosave or full undo. Save before closing the tab or trying a pattern or size change that resets strip edits. Opening another valid project replaces that mode's design and retains the other mode, so save your current work first. An invalid or unsupported file leaves the current design in place.

Export your artwork

Choose Export artwork as SVG for a static vector image. The download preserves the current colors, visibility, spacing, and interlacing, and removes controls and scripts. Use Save Project when you want to continue editing later.

The original 2012 workflow used Firefox's Save As → Web Page, Complete to capture an editable SVG. The new Save Project button makes saving explicit and includes the assets needed to reopen the design.

Browser and device notes

The integrated planar/corner editor and editable project workflow are tested in Chromium, Firefox and Playwright WebKit. It uses native SVG and JavaScript; no Adobe plug-in, Java, or Batik installation is needed for the web editor. Mac Safari and physical touch devices still need hands-on verification.

The original controls rely on mouse hover and mouse-down events. Use a mouse or trackpad. The embedded editor keeps a minimum width for legible controls; scroll horizontally on narrow screens. Corner mode rearranges its shared controls for narrow widths and provides keyboard palette/inspection operations. The planar SVG editor still lacks complete keyboard operation.
