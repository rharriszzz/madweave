Planar and corner designs

Weave editor

Open SVG directly

Choose a color along the top, then click a strip. Hover over a control for its description. A mouse or trackpad works best. Use Flat, Corner, and Angle below the drawing to change views. On smaller screens, scroll the editor sideways.

Each mode retains its unsaved work in this session. Save stores the active design only.

Strip and seam inspection

N/M/W/E changes spacing. Lower-left 1–8 matches the original strip counts at 360°; other angles scale the count proportionally. Strips end individually near a circular outline. Colors on surviving strips remain. C/hand/X, direction filters and I/V material hiding are unavailable in corner mode. CP previews and CC1/CC3 set or stage formula coloring; other color counts are unavailable.







Save Project stores the active design, including selection, in a self-contained file. Inactive unsaved work stays in this session only. Open accepts planar and corner projects. SVG is artwork; corner physical constructibility is unverified. There is no autosave.



Quick control reference
Left: five patterns, 1–6 pattern colors, and size 1–8 (3–24 strips per direction in Flat view). Top: eight palette colors and recent colors. Right: color sliders, orientation, layers, directions, outlines, and N/M/W/E spacing. Bottom: HB hides the SVG controls.
Pattern and color-count buttons reset manual strip edits. Changing the Flat size resets strip edits; Corner size changes retain colors on surviving strips. There is no undo or automatic saving.
