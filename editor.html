The interactive pattern editor

Make your weave.

Open SVG directly ↗

Choose a color along the top, then click a strip. Hover over a control for its description. A mouse or trackpad works best. On smaller screens, scroll the editor sideways.

Save Project downloads an editable file you can reopen, even offline. Open Project also accepts original editable SVG files. Export artwork downloads a static image. Save before closing; there is no autosave.

Quick control reference

Left: five patterns, 1–6 pattern colors, and size 1–8 (3–24 strips per direction). Top: eight palette colors and recent colors. Right: color sliders, orientation, layers, directions, outlines, and N/M/W/E spacing. Bottom: HB hides the SVG controls.

Pattern and color-count buttons reset manual strip edits. Changing the size resets strip edits when the strip count changes. There is no undo or automatic saving.
