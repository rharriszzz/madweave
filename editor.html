Weave editor

Open SVG directly

Choose a color along the top, then click a strip. Hover over a control for its description. A mouse or trackpad works best. On smaller screens, scroll the editor sideways.

Each mode retains its unsaved work in this session. Save stores the active design only.

Strip and seam inspection

Size, spacing, C/hand/X, direction filters and I/V material hiding are unavailable in corner mode. The phase/crop defines supported geometry. Palette transparency is supported; material remains present even when transparent. CP previews and CC1/CC3 set or stage formula coloring; other counts are unavailable.





Save Project stores the active design, including selection, in a self-contained file. Inactive unsaved work stays in this session only. Open accepts planar and corner projects. SVG is artwork; corner physical constructibility is unverified. There is no autosave.



Quick control reference
Left: five patterns, 1–6 pattern colors, and size 1–8 (3–24 strips per direction). Top: eight palette colors and recent colors. Right: color sliders, orientation, layers, directions, outlines, and N/M/W/E spacing. Bottom: HB hides the SVG controls.
Pattern and color-count buttons reset manual strip edits. Changing the size resets strip edits when the strip count changes. There is no undo or automatic saving.
